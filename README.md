# Sales Management System

A Python-based Sales Management System built using Object-Oriented Programming and a modular project structure. The system allows users to manage customers, products, employees, and sales through a menu-driven interface.

## What I Learned

Through this project, I practiced:

* Object-Oriented Programming (OOP) in Python
* Creating and using classes and objects
* Modular programming using multiple Python files
* CRUD operations — Create, Read, Update, Delete
* Working with customer, product, employee, and sales records
* Data analysis and basic statistics using Pandas
* Generating sales reports
* Filtering and sorting datasets
* Data cleaning
* Importing and exporting datasets
* Exception handling using `try-except`
* Building a menu-driven console application

## Features

### Record Management

* Add customer, product, employee, and sales records
* Search records
* Update records
* Delete records
* View records

### Reports

* Monthly reports
* Yearly reports
* Top products
* Best customers
* Best employees

### Analytics

* View dataset
* Calculate statistics
* Find highest and lowest sales
* Calculate average sales
* Calculate total revenue
* Sort and filter sales
* Analyze monthly and product sales
* Clean data
* Generate random sales data

### Import & Export

* Import datasets
* Export reports

## Project Structure

```text
Sales-Management-System/
│
├── main.py
├── customer.py
├── product.py
├── employee.py
├── sales.py
├── report.py
├── analytics.py
├── import_export.py
└── README.md
```

Each module is responsible for a specific part of the system, making the project easier to manage and understand.

The program starts with a main menu where the user can choose different operations.

```text
Main Menu
   │
   ├── Add Records
   ├── Search Records
   ├── Update Records
   ├── Delete Records
   ├── View Records
   ├── Reports
   ├── Analytics
   ├── Import / Export
   └── Exit
```

## Purpose

I created this project to practice building a larger Python application using **OOP and multiple modules** instead of keeping everything in a single file. It helped me understand how different classes and components can work together to build a complete management system.
